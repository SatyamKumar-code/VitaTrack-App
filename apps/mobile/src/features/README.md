# VitaTrack Mobile Features Directory

This directory hosts business domain features following the **Feature-First (Vertical Slice) Architecture**:

- `auth/`: Onboarding slides, login/register forms, session state (Phase 2).
- `assessment/`: Multi-step questionnaire wizard, symptom cards, sunlight slider, diet picker (Phase 3).
- `scoring/`: Animated circular risk gauge, contributor breakdowns, doctor alerts (Phase 4).
- `guidance/`: Tailored meal cards, outdoor sunlight exposure timer, bone health exercises (Phase 5).
- `wearables/`: Health Connect bridge, synced metric cards, connection status pills (Phase 8).
- `reports/`: Longitudinal assessment trend graphs and clinician PDF exporter (Phase 6).
- `reminders/`: Daily sunlight and lifestyle local notification scheduler (Phase 7).
