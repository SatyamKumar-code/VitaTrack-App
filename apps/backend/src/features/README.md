# VitaTrack Backend Features Directory

This directory hosts business domain features following the **Feature-First (Vertical Slice) Architecture**:

- `auth/`: User registration, JWT login, token rotation, profile management (Phase 2).
- `assessment/`: Clinical self-assessment questionnaire & deterministic scoring engine (Phase 3 & 4).
- `guidance/`: Nutritional, safe solar, and musculoskeletal exercise recommendations (Phase 5).
- `wearables/`: Android Health Connect biometric ingestion & normalization (Phase 8).
- `reminders/`: Notification schedules for sun exposure and dietary habits (Phase 7).
- `admin/`: Technical operations, system health, and Zero-PHI metrics (Phase 9).
